| เรื่อง | สูตร |
|---|---|
| CIDR /x | จำนวน address = $2^{32-x}$ · mask = x บิตแรกเป็น 1 |
| แบ่ง block | ยืม k บิต → $2^k$ ก้อน ก้อนละ $/(x+k)$ |

## ลำดับขั้นที่ต้องเรียงได้

- **DHCP:** discover → offer → request → ACK (ทั้งหมด broadcast) ได้ IP + gateway + DNS + mask
- **NAT:** ขาออกเปลี่ยน (src IP, port) → (NAT IP, port ใหม่) + จดตาราง · ขาเข้าเปลี่ยน dest กลับ
- **ARP:** query broadcast → reply unicast → จดตาราง ⟨IP, MAC, TTL⟩
- **Switch:** จำ src MAC + interface → ค้น dst → เจอ: forward / drop (ฝั่งเดียวกัน) · ไม่เจอ: flood
- **ข้าม subnet:** frame A→R (MAC dest = R) → R สร้าง frame ใหม่ R→B (MAC dest = B) · IP เหมือนเดิมตลอด
- **Traceroute:** UDP TTL = 1, 2, 3 … (ชุดละ 3) → เราเตอร์ตอบ 11/0 → ปลายทางตอบ 3/3 → หยุด
- **SDN ลิงก์เสีย:** port status → อัปเดต link status → เรียก Dijkstra app → คำนวณ route → คำนวณ flow table → ติดตั้งผ่าน OpenFlow
- **BGP route selection:** local preference → AS-PATH สั้นสุด → NEXT-HOP ใกล้สุด (hot potato) → อื่นๆ
- **Web request:** **DHCP → ARP → DNS → TCP → HTTP**
- **CSMA/CD:** ฟัง → ส่ง → ชน = หยุด + jam → binary backoff → ฟังใหม่

## เทียบคู่ที่ออกบ่อย

| คู่ | ฝั่งซ้าย | ฝั่งขวา |
|---|---|---|
| Forwarding / Routing | ในเราเตอร์ตัวเดียว · data plane · ns | ทั้งเส้น · control plane · ms |
| Per-router / SDN | ทุกเราเตอร์คำนวณเอง | remote controller คำนวณให้ |
| Input / Output queue | HOL blocking | drop policy + scheduling |
| LS / DV | global, Dijkstra, O(n²) msgs, oscillation | เพื่อนบ้าน, Bellman-Ford, count-to-infinity, black-holing |
| Intra / Inter-AS | RIP, EIGRP, OSPF · เน้น performance | BGP · policy สำคัญกว่า |
| OSPF / BGP | flood LSA บน **IP** · Dijkstra | path vector บน **TCP** |
| eBGP / iBGP | ระหว่าง AS | ภายใน AS |
| Northbound / Southbound | controller ↔ app | controller ↔ switch (OpenFlow) |
| IPv4 / IPv6 | มี checksum, fragmentation, options | ตัดทิ้งทั้ง 3 · flow label |
| IP / MAC | 32 บิต, layer 3, ย้ายไม่ได้ | 48 บิต, layer 2, flat portable |
| Router / Switch | IP, routing algorithm | MAC, flooding + self-learning |
| 1D / 2D parity | ตรวจได้ (คี่บิต) แก้ไม่ได้ | แก้ single-bit ได้ |

## กับดักที่คนพลาด

<Warn title="อ่านก่อนเข้าห้อง">

- นับ subnet แล้ว**ลืมลิงก์ระหว่างเราเตอร์**
- fragment **ลืมบวก header 20** และลืมว่า offset **หาร 8**
- reassembly ทำที่**ปลายทางเท่านั้น** ไม่ใช่เราเตอร์กลางทาง
- longest prefix: match หลายแถว **ไม่ใช่เลือกแถวแรก** แต่เลือก**ยาวสุด**
- ใน tunnel IPv4 header src/dest = **ปลายท่อ (B, E)** ไม่ใช่ A, F
- ข้าม subnet: frame แรก MAC dest = **router** ไม่ใช่ B
- **ARP มาก่อน DNS** ใน a day in the life
- Ethernet **ไม่ส่ง ACK** (unreliable, connectionless)
- `*` ใน traceroute **ไม่ได้แปลว่าเส้นทางเสีย**
- ICMP ถูกห่อใน IP จึงอยู่ **"เหนือ" IP**
- 1D parity ผิด **2 บิต ตรวจไม่เจอ**

</Warn>
